# FrontierGuard DEA 0.1.0a1

Release date: 2026-07-27
Release type: alpha research preview

## Purpose

This release establishes FrontierGuard DEA as an installable, citable research
software project. It combines the implemented DEA foundation with transparent
scholarly metadata, an initial technical white paper, and an executable
conformance-benchmark protocol.

Alpha status means that APIs may still change and that methods marked
`provisional` or `experimental` have not yet satisfied the full independent
cross-language validation gate.

## Highlights

- Classical radial, additive, directional, SBM, FDH, scale, super-efficiency,
  multiplier, cross-efficiency, and assurance-region workflows.
- Cost and revenue efficiency with technical and allocative decomposition.
- Adjacent-period Malmquist productivity analysis.
- Serial multi-stage and experimental graph-defined relational network DEA.
- Independent residual audits, immutable results, method metadata, and evidence
  bundles.
- White Paper v0.1 and explicit AI-use and contributor-role records.
- Initial cross-language conformance protocol, machine-readable cases, and
  adapter contracts.

## Known limitations

- The general graph-defined network engine is experimental.
- The full R, Julia, MATLAB, and independent-Python comparison suite is not yet
  complete.
- Statistical bootstrap inference, environmental DEA, robust partial
  frontiers, dynamic network SBM, and several non-radial families remain on the
  roadmap.
- This release and its white paper have not been peer reviewed.

## Rollback and correction policy

PyPI files and published tags are immutable. If a release-blocking problem is
found, do not replace the tag or distribution:

1. Mark the GitHub release as affected.
2. Yank the PyPI version if installation or scientific correctness is unsafe.
3. Open a public issue unless the defect is security-sensitive.
4. Fix forward in a new version and document the correction in the changelog.

Rollback is triggered by an installation failure on a supported Python version,
a material mismatch between published artifacts, an incorrect advertised
scientific result, or a critical security problem.
