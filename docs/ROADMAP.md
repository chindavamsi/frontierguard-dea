# Roadmap

## Phase 0 — Contracts and reference corpus

- Complete the R/Python/Julia feature inventory.
- Curate published datasets with reproducible expected values.
- Freeze score, orientation, RTS, slack, target, and infeasibility conventions.
- Establish the solver conformance suite.

## Phase 1 — Classical production technology

- Radial envelopment and multiplier models.
- CRS, VRS, NIRS, NDRS, generalized RTS.
- Slacks, targets, peers, dual weights, scale efficiency, RTS classification.
- Super-efficiency, additive, directional, SBM, and FDH families.
- Weight restrictions and non-discretionary variables.

## Phase 2 — Multi-stage and internal structure

- Serial relational networks for arbitrary stage counts.
- Parallel and general DAG structures.
- Shared inputs/outputs, exogenous stage resources, undesirable links.
- Network SBM, dynamic networks, and carry-overs.
- Stage peers, targets, and decomposition diagnostics.

## Phase 3 — Productivity, economics, and environment

- Cost, revenue, profit, profitability, and allocative efficiency.
- Panel/window analysis.
- Malmquist, global Malmquist, and Malmquist–Luenberger.
- Environmental and weak-disposability models.

## Phase 4 — Statistical and robust inference

- Simar–Wilson bootstrap bias correction and intervals.
- RTS tests and group/frontier comparisons.
- Order-m/order-alpha partial frontiers.
- Double-bootstrap second-stage analysis.
- Perturbation, influence, rank, peer-set, and frontier stability.

## Phase 5 — Research workflow and scale

- Sparse/batched model construction and parallel solving.
- Extend current Markdown/CSV/JSON evidence bundles with publication plots and
  HTML reports.
- Extend the current discovery/diagnostics CLI into data-driven CLI and
  notebook workflows.
- R/Julia interoperability and migration guides.
- Stable 1.0 compatibility and governance policy.
