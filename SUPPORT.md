# Support

FrontierGuard DEA is a volunteer-maintained research project and does not
provide guaranteed response times or consulting services.

Before asking for help:

1. read the [README](README.md) and documentation under [`docs/`](docs/);
2. check the [feature matrix](docs/FEATURE_MATRIX.md) to confirm the method is
   implemented and validated;
3. search open and closed GitHub issues; and
4. reduce the problem to a small, non-confidential example.

Use the repository's structured issue forms:

- **Usage or research question** for model selection and interpretation;
- **Bug or incorrect result** for reproducible unexpected behavior;
- **DEA method or feature proposal** for a new formulation; and
- **Documentation improvement** for unclear or missing guidance.

Never post confidential, proprietary, personally identifying, or otherwise
sensitive research data. Use synthetic values that preserve the relevant
structure.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md). Code of Conduct incidents use the private process in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
